# Security policy

Raion deploys and configures infrastructure, so we treat security issues as top priority.

## Reporting a vulnerability

**Please do not open a public issue.** Use GitHub's private vulnerability reporting ("Report a vulnerability" under the repository's _Security_ tab). We aim to acknowledge reports within 3 working days and to agree a disclosure timeline with you.

Please include the affected version, a description of the impact, and steps to reproduce.

## Supported versions

Raion is pre-1.0. Security fixes are made on the latest release only.

## Scope

In scope:

- the Raion server (API, authentication, sessions, authorization)
- the CLI
- configuration generated by Raion
- integration packaging

Out of scope:

- vulnerabilities in the upstream components Raion configures (Prometheus, Grafana, Loki, Tempo, Alertmanager, OpenTelemetry). Report those upstream.
- misconfigurations that the documentation explicitly warns against
